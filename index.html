What's New v5.8.1.0-r16:
5.8.1.0-r16 (patch release): fixed items
5.8.1.0-r16 is a patch release of 5.8.1.0. Two installers are published together: the online installer (Normal) and the offline installer (AirGap) for Revit 2027, named ZXBuilder2027_Normal_v5.8.1.0-r16_Setup_Pre-Beta.msi and ZXBuilder2027_AirGap_v5.8.1.0-r16_Setup_Pre-Beta.msi (Normal = online installer, AirGap = offline installer). Starting with 5.8.1.0-r13, Revit 2026 is no longer supported (ZXBuilder2026 is no longer available for download); only the Revit 2027 version is provided. Release time: 2026-10-19 11:30 (Taipei time). Size and SHA-256 of the two installers: ZXBuilder2027_Normal_v5.8.1.0-r16_Setup_Pre-Beta.msi is 229,232,640 bytes, SHA-256 CD61AB8F7E1DE36698C3F28BA8FD7AAE8F86276AF9EE24BCD7EC784B85D594AC; ZXBuilder2027_AirGap_v5.8.1.0-r16_Setup_Pre-Beta.msi is 228,577,280 bytes, SHA-256 93B334D9054FDC925C283851EACC6B79B5C1795BCF8B4E33AF3A0C3A21735899. After downloading, please verify with SHA-256; these are two different files, so check each one against its own value. Installing 5.8.1.0-r16 includes all content of 5.8.1.0-r15, 5.8.1.0-r14, 5.8.1.0-r13, 5.8.1.0-r12, 5.8.1.0-r11, 5.8.1.0-r10, 5.8.1.0-r9, 5.8.1.0-r7, 5.8.1.0-r6, 5.8.1.0-r4, 5.8.1.0-r2, 5.8.1.0-r1 and 5.8.1.0. How to install: run the installer. After installation, open any project in Revit, then open the ZXBuilder "About" screen; if the version number on the Version line begins with 5.8.1.0-r16, 5.8.1.0-r16 is installed.
Verification scope: After the digital signature was applied to both installers, we re-tested on Revit 2027 using the same signed program that is inside the published installers: the final step of export in the offline installer, the publisher marking when building a library in the offline installer, export in the online installer, and a comparison of diagnostic records between the internal test build and the release build on the same set of test files (all differences are known and do not affect import results). All passed.
Items fixed in 5.8.1.0-r16 (included in both installers):
1. The final step of Export USD in the offline (Air-gap) installer now works the same as in the online installer. In the v5.8.1.0-r15 offline installer, the check in the final step of export did not pass, so the output file from before this step was kept; the online installer was not affected. In this release, the offline installer passes this check, and the output file goes through the same processing as in the online installer. Our measured result: using the program inside the digitally signed offline installer, we exported an HVAC model once on Revit 2027: the final step of export was not rolled back (0 times), the temporary file was replaced with a single file 1 time (86,234,077 bytes), and the export ended in a normal state; no temporary files were left in the output folder, and no extra subfolders were created. The signed program of the online installer was also tested once: the final step of export was not rolled back (0 times), and the temporary file was replaced with a single file 1 time.
2. When importing back into Revit with the source model file (.rvt) found, and with the project base point and survey point already set in the target project, some air terminals lost their associated level and their positions fell to near elevation 0: fixed in this release. Our measured result: using the internal test build, we tested one model on Revit 2027 (the source model file was found during import back into Revit; the receiving project had loaded the six linked models that the source model links to): all 509 air terminals imported back have an associated level; for the 9 air terminals checked one by one, the difference from the expected position is within 0.03 mm (the expected position is the source position adjusted by the family's standard connector distance of 47.625 mm); when compared directly with the source model's coordinates, all 9 air terminals show the offset expected from adjustment by the family's connector rules: 3 of them differ in height by up to about 1.85 mm, and the other 6 are within 0.23 mm. The completion window of this import back also shows a line "Could not verify source: ... could not be compared with the original model recorded at export; import back proceeded as usual", which means that during import back, the source model file that was found could not be checked against the original model recorded at export to confirm they are the same file, and import back still proceeded as usual; the results above for the 509 and 9 air terminals were measured in the same import back in which this line appeared. In addition, a scene containing 3 DP panels was exported from Revit and imported back into Revit in a project with the project base point set: the positions of the 3 DP panels differ from the source by 0 mm (reading 0.000000 mm; our target is within 0.5 mm).
3. When importing back into Revit without the source model file (.rvt) found, air terminals are reconnected to the ducts they connect to. Our measured result: using the internal test build, we tested one model on Revit 2027 (the source model file was not found during import back into Revit): of the connectors of 103 air terminals, 102 connectors are connected, and the connector of 1 (a linear air terminal) is not connected; all 103 air terminals are retained after import back and saving, with the same orientation as in the source model.
4. When importing back into Revit without the source model file (.rvt) found, 9 pairs of duct fitting connectors that previously were not connected are now connected in this release. Our measured result: using the internal test build, we tested an HVAC model on Revit 2027 (the source model file was not found during import back into Revit): all 9 pairs of connectors are connected; the 2,692 pairs of connectors already connected before the fix were not disconnected as a result. The known issue of 8 pairs of unconnected connectors listed in Section 7 of the "Release Notes" was measured on Revit 2026; since Revit 2026 is no longer supported starting with 5.8.1.0-r13, this release was not re-tested on Revit 2026.
5. After duct accessories are imported back into Revit, the number of connectors, connector shape, connector size and "System Type" are the same as in the source model (the comparison is of each connector's width, height or diameter). Our measured result: using the internal test build, we tested a model containing 17 duct accessories on Revit 2027 (the source model file was not found during import back into Revit): for 17 / 17 items, the number of connectors and connector shape are the same as in the source model, and the connector size difference is within 0.001 ft (about 0.3 mm); for 17 / 17 items, the "System Type" is the same as in the source model.
6. Item 1 fixed in v5.8.1.0-r15 (keeping main ducts fixed and adjusting only the ends during import back into Revit) has been re-verified on this release. Our measured result: using the internal test build on Revit 2027, we re-tested the same model (with the original Revit file placed in the same folder during import back into Revit): for 1,053 / 1,053 ducts, the length differs from the source model by within ±0.1%; the case described in v5.8.1.0-r15 where "the source model file is not found during import back into Revit" was not re-run on this release.
7. Ducts, duct fittings and ducts of three cross-section shapes have been re-verified on Revit 2027. Our measured result: using the internal test build on Revit 2027, we exported the sample model "Snowdon Towers Sample HVAC" included with Revit 2027 using "Export USD" and imported it back into Revit (with the original Revit file placed in the same folder during import back): for 1,053 / 1,053 ducts, size, length and system type match the source model (size difference within 0.5 mm, length difference within ±0.1%); for 997 / 997 duct fittings, family, type and system type are consistent with the source model, with size difference within 0.5 mm. When the file exported from the same model by the internal test build was instead imported back into Revit with the main program file inside the published v5.8.1.0-r14 installer (with the original Revit file placed in the same folder during import back), 3 short ducts had lengths that did not match the source (differences of 3.65%, 2.03% and 1.66%). In addition, a ZX USDC scene file containing 1 duct each of rectangular, round and oval cross-sections was imported into Revit 2027: all three cross-sections were created, 1 each, the same as in the scene file.
8. Shared nested sub-components in families (for example, sub-lamps on a pendant lamp fixture, window frame trims, muntins) are no longer placed as an additional separate copy during import back into Revit; instead, the sub-components that Revit creates automatically when the parent component is placed are used. When the parent component is not placed, the sub-components are placed in the original way. Our measured result: using the internal test build on Revit 2027, we tested the sample model "Snowdon Towers Sample Architectural" included with Revit (the source model file was not found during import back into Revit); after import back and saving, the counts of the following families and types are all the same as in the source model: Pendant Lamp - Art Glass - LED (Standard) 16 items, Chair-Breuer 102 items, Trim-Window-Interior-Flat (Picture Frame) 66 items, Trim-Window-Exterior-Flat (Picture Frame 36 items, with Sill 20 items), Muntin Pattern_2x3 (Muntin Pattern_2x1) 64 items.
